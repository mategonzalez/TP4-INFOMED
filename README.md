### Objetivo del Trabajo

El propósito del trabajo fue diseñar, consultar y analizar una base de datos relacional asociada a un sistema de gestión de pacientes, profesionales y consultas médicas.  
Se aplicaron los conceptos trabajados en la materia relacionados con:

- Diseño lógico de bases de datos relacionales
- Consultas SQL (SELECT, JOIN, GROUP BY, HAVING)
- Actualización y modificación de registros (UPDATE)
- Optimización mediante índices
- Manejo de control de versiones con Git y GitHub
